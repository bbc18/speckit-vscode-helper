## 2025-06-15 - [CRITICAL] Prevent Command Injection with child_process.execFile
**Vulnerability:** Command injection risk when using `child_process.exec` with string concatenation, particularly when handling user-provided branches and file paths in `worktreeService.ts` and `worktreeAggregator.ts`.
**Learning:** `git worktree add` uses branches and paths that might contain characters that `child_process.exec` evaluates in a shell, making it susceptible to injection if inputs aren't completely sanitized. The existing architecture using `child_process.exec` with a concatenated string makes escaping difficult and fragile. Furthermore, when verifying a branch with `git rev-parse --verify`, appending `--` before the branch argument causes `git` to treat the target as a file, causing verification to incorrectly fail.
**Prevention:** Avoid `child_process.exec` entirely. Prefer `child_process.execFile` with an explicitly passed executable (`file: 'git'`) and a strict array of arguments (`args: string[]`). To prevent argument injection where positional arguments might be misinterpreted as flags, use the `--` separator before positional arguments (`git worktree add -- <path> <branch>`), except when the specific command, like `git rev-parse --verify`, behaves differently when using `--`.
