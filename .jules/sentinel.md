## 2025-02-17 - [Fix Command Injection in Git Exec]
**Vulnerability:** Command injection vulnerability in `worktreeService.ts` when using `childProcess.exec` with untrusted data (`branch`, `targetPath`). The untrusted values were directly interpolated into a command string and executed via a shell.
**Learning:** `childProcess.exec` executes a string command within a shell. If any user input or dynamic values are passed, they must be meticulously escaped, which is error-prone.
**Prevention:** Always use `childProcess.execFile` and pass arguments as an array instead of passing string representations of commands. This ensures variables are treated strictly as positional parameters. Additionally, always use the `--` flag when passing file paths or ref names to avoid command argument injection (e.g., `git rev-parse --verify -- <branch>` vs `git rev-parse --verify <branch>`). Note: `git rev-parse` fails when passing a branch with `--` separation since `--` instructs `git` to interpret it as a file/path instead of a branch.
