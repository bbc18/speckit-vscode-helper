## 2026-05-26 - Command Injection via child_process.exec in Git commands
**Vulnerability:** The application used `child_process.exec` with interpolated strings for executing Git commands, allowing potential command injection if arbitrary user input is supplied as branch names or arguments.
**Learning:** `child_process.exec` passes the entire command string to a shell, parsing it according to the shell rules. This is dangerous if untrusted data reaches the command arguments. Using arrays with `child_process.execFile` sidesteps shell parsing altogether, inherently avoiding command injection. Also, using `--` as a delimiter is required when user input is used in command line flags or paths to prevent option injection.
**Prevention:** In order to prevent command injection issues when running external tools like git, always use array-based parameter invocation using `child_process.execFile` or `child_process.spawn`. Keep user input safe from being interpreted as an option flag by placing it after a `--` delimiter.
