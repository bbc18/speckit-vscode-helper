## 2026-05-21 - [Prevent Command Injection in Git Execution]
**Vulnerability:** `childProcess.exec` was used to execute git commands constructed via string interpolation (e.g., ``execGit(`git rev-parse --verify "${branch}"`)``), creating a severe command injection vulnerability if user-controlled input like `branch` or `targetPath` contained shell metacharacters (e.g., `"; rm -rf /"`).
**Learning:** Shell-based command execution (`exec`) automatically invokes the system shell, which interprets shell metacharacters. Building commands dynamically via string concatenation with untrusted input is inherently unsafe in this pattern.
**Prevention:** Replaced `childProcess.exec` with `childProcess.execFile` and structured `ExecFn` to take `args: readonly string[]`. This securely passes the command and its arguments as an array directly to the OS executable, avoiding shell interpretation entirely. Added `--` before positional arguments to prevent argument injection where applicable.
