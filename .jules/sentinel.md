## 2026-06-15 - Command Injection via `childProcess.exec`
**Vulnerability:** The application used `childProcess.exec` to execute Git commands (`git worktree add`, `git rev-parse --verify`, etc.), concatenating user-controlled inputs like branch names and target paths directly into the command string. This is susceptible to command injection if a branch name or path contains shell metacharacters like `;`, `&`, `|`, `$()`.
**Learning:** `childProcess.exec` invokes a shell to evaluate the command string, making any unsanitized user input in the string a critical command injection vector.
**Prevention:** Use `childProcess.execFile` and pass arguments as an array (`args`) instead of a single concatenated string. This bypasses the shell entirely, passing arguments directly to the executable. Also, use `--` in Git commands (where appropriate, like `git worktree add -- <path> <branch>`) to prevent options injection. Note: Do not use `--` with `git rev-parse --verify` as it treats the argument as a file path instead of a revision.
